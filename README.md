# DJY EV 가상 배기음

[브라우저에서 엔진음 듣기](https://djy-ops.github.io/DJY_EVVESS/)

RB7(V8)과 Ferrari F2001(V10)을 한 페이지에서 선택할 수 있습니다. 각 데모에서 **시동 걸기**를 누르고 가속·제동을 조작하면 RPM과 변속에 따라 소리가 달라집니다. 음원과 재생 코드는 각 HTML 안에 들어 있어 파일을 내려받아 로컬 브라우저에서도 사용할 수 있습니다.

## EV 하드웨어 연결 계획

현재 구현은 브라우저 프로토타입입니다. 다음 단계는 실제 차량 데이터를 ESP에서 받아 차량 스피커로 재생하는 것입니다.

1. **차량 입력** — 모터 RPM과 가속 페달 값을 받아 브라우저에서 조정한 음색·변속 로직에 연결합니다. 기록된 주행 데이터를 먼저 재생해 결과를 비교합니다.
2. **오디오 보드 선정** — 목표 구성은 **ESP → I²C 제어 → 오디오 보드·앰프 → 스피커**입니다. I²C로 재생·음량을 제어하는 모듈을 선택하거나, ESP가 직접 PCM을 생성하면 I²S로 오디오 데이터를 보내고 I²C는 코덱 설정에 사용합니다. 출력단은 스피커를 구동할 수 있는 앰프로 구성합니다.
3. **벤치 검증** — ESP의 메모리와 처리량에 맞춰 음원 레이어를 구성하고, RPM 변화에 대한 지연·끊김·음량과 입력 단절 시 음소거를 확인합니다.
4. **차량 적용** — 전원·배선·스피커 장착을 확인한 뒤 정차 상태에서 시작해 주행 로그와 실제 소리를 비교합니다.
